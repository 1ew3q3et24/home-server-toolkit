== 2. 三个真实场景都落在这个组合上 ==
   - 家庭出口断网（ISP 故障）：心跳写不出去 -> 过期；外网 25565 不可达；家里 MC 仍在局域网内运行并写盘
     hb=False port=False -> home-mc-alive='0 none' -> 214-223 防双写检查说家里已停 -> 切云 -> 切云=True
   - 家庭侧心跳写入端先坏（cron/ssh 断）+ 端口映射同时失效（CGNAT 换了映射）：MC 本身还活着
     hb=False port=False -> home-mc-alive='0 none' -> 214-223 防双写检查说家里已停 -> 切云 -> 切云=True
   - 对照：家里真的关机了（同样 hb/端口都断，但 MC 确实没在跑）
     hb=False port=False -> home-mc-alive='0 none' -> 214-223 防双写检查说家里已停 -> 切云 -> 切云=True

   关键：前两个场景与“家里真的关机”在云端看来**完全一样**（都是 0 none），
