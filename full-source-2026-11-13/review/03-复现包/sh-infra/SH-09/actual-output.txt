   输入 '/usr/lib/jvm/java-17-openjdk-amd64/bin/java/2637/0' -> name=''         allow命中=False
   输入 '/usr/bin/sshd/901/0'                                -> name=''         allow命中=False
   输入 '/usr/lib/systemd/systemd/1/0'                       -> name=''         allow命中=False
   输入 'java/2637/0'                                        -> name='java'     allow命中=True
   输入 'unknown TCP/0/0'                                    -> name='unknown'  allow命中=False
   输入 '/usr/bin/wget/4321/0'                               -> name=''         allow命中=False

   [判定] 绝对路径样本解析出的名字: ['']
   白名单对“绝对路径程序”永远不命中: 是

== 2. 判定方向：allow_hit 会让 503 永不开启，即使带宽打满 ==
   条件（ddos-monitor.py:114）：top.name in ALLOW and rate >= total_kbs*0.6
   top.name     rate(KB/s) total      allow_hit  high(80%) 
   'java'       900.0      1000.0     True       False     
   'sshd'       900.0      1000.0     True       False     
   'systemd'    900.0      1000.0     True       False     
   ''           900.0      1000.0     False      True      
   'unknown'    900.0      1000.0     False      True      
   'wget'       900.0      1000.0     False      True      

   => 本地任意进程只要名字叫 java/sshd/systemd，且是最大流量来源，
      就把 high 变成 False：攻击流量（含来自该进程的外发）完全不触发 503。
      而正常 MC 若以绝对路径出现在 nethogs 里，名字被解析成 ''，反而触发 503。
