  ai-bot-action.php ban_user（AI 审批）              sessions_valid_after=无     trusted_devices=无     -> 未吊销 <<<
  lib.php upload_deny（上传违规永久封禁）                  sessions_valid_after=无     trusted_devices=无     -> 未吊销 <<<
