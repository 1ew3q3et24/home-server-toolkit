== 检查结果 ==
  1) api-version = '26.2' -> 是否符合 Bukkit '1.x' 格式: 否
     Bukkit/Paper 把 api-version 解析为服务端版本, 高于当前服务端版本会抛
     UnsupportedApiVersionException 并禁用插件; '26.2' 在 1.13~1.21 上不属于合法/受支持值。
     包内没有 server.properties/服务端版本证据(nginx 与服务端配置缺失), 故加载结果只能
     到真机确认; 但无论如何该值都不符合惯例, 属于部署风险。
  2) main = com.lzj.mcgate.McGate -> 源文件是否存在: 是
  3) Paper 专属 import: ['io.papermc.paper.event.player.AsyncChatEvent']
     plugin.yml 未声明 depend/softdepend/libraries => 在 Spigot/CraftBukkit 上
     io.papermc.paper.event.player.AsyncChatEvent 会 NoClassDefFoundError, registerEvents 失败,
     插件被禁用(闸门消失)。
  4) commands         声明: 无
  4) permissions      声明: 无
  4) depend           声明: 无
  4) softdepend       声明: 无
  4) load             声明: 无
  4) libraries        声明: 无
  4) folia-supported  声明: 无
